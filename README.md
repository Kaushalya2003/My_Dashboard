Lanka Fresh Mart Dashboard

Name:W.M.N.Kaushalya
Index Number: MGT/8685

Project Description
  A responsive dashboard for Lanka Fresh Mart,displaying sales information,total revenue,total units sold,the best-performing month,and the best branch.

Technologies Used
   HTML
   CSS
   JavaScript
   Chart.js
   Font Awesome
   Google Fonts(Poppins)

 Layout and Responsiveness
   CSS Grid - Used to arrange KPI cards and chart cards.
   Flexbox - Used for the sidebar, navigation links, header, and alignment of elements.
   Media Queries - Used to adapt the dashboard for tablet and mobile screen sizes.
   JavaScript -  Used to calculate dashboard values, display charts, and control the mobile navigation menu.

Known Issues
   Dashboard valuea are based on sample data.
